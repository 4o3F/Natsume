# v2.10.1

**DOMjudge 导出校徽统一为 64×64，并更新 rustls 安全补丁。**

## 主要变化

- Preparation Center 下载 DOMjudge ZIP 时，所有可用的 PNG／JPEG／WebP／SVG 校徽统一输出为 64×64 PNG。SVG 先按自然画布渲染，随后与栅格图一样使用 Lanczos3 等比重采样，居中补透明边，不拉伸、不裁切。
- 重采样使用预乘 alpha 并保留 Lanczos 滤波余量，避免透明边缘串色。源图片、网页及 Client 的 Logo 获取行为保持不变；缺图／歧义省略及损坏／不可读／超限图片中止整包的规则保持不变。
- rustls 从 0.23.45 升级至 0.23.46，修复依赖安全检查报告的 RUSTSEC-2026-0346、0347、0348、0349 告警，不改变启用的 features。

## 升级说明

不增加数据库 migration，不修改 Device Control、本地 D-Bus 方法签名或部署配置格式。升级 Server 后重新下载 DOMjudge ZIP，即可取得新尺寸校徽，无需修改源图片或重新导入名单。已有的 DOMjudge 校徽需由部署方用新导出文件替换。
