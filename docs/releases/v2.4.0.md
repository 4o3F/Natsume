# v2.4.0

**新增短时有效的在线设备集体关机，并完善运维列表筛选与 DOMjudge 数据导出。**

## 主要变化

- 管理员可对当前在线且 Enabled 的设备提交一次性集体关机请求；请求仅在 60 秒内有效，离线设备不会在后续重连时补执行。Client 使用 root-only Helper 通过 logind 请求正常关机，同一 epoch 在重启后不重放。
- Device lifecycle 筛选改为原子状态组合：`GET /api/v2/devices?state=enabled,revoked`。`all` 与 `non_revoked` 已移除；Server、Web 和自定义 API 调用方必须使用 `enabled`、`disabled`、`revoked` 的逗号组合。
- Targets、Devices、Seats 和 Accounts 页面新增组合状态／列筛选；Seats 显示 Bound/Unbound 状态并以行底色辅助识别。
- DOMjudge ZIP 只包含数据 JSON/YAML 与可用徽标，不再附带 `README.md`。缺失或歧义徽标会省略，不阻塞导出；损坏、不可读或超限的匹配徽标仍使导出失败。

## 升级

Server、Device Daemon、Privileged Helper、Session Agent 和 Web 必须作为一个版本整体升级。保留数据库、设备身份、Control/Gateway 凭据、Binding、Home 状态和完整配置；不要重新 bootstrap 或清除状态。

升级前检查所有使用 `/api/v2/devices` 的运维脚本：将旧的 `state=all` 或 `state=non_revoked` 改为省略 `state`，或使用原子状态的逗号组合。安装新 Deb 后重启 Server 与 Client 服务，使新控制协议和 root-only 关机能力同时生效。
