# v2.5.0

**Waiting 页面新增项目标识、作者署名与离线可用的高清头像。**

## 主要变化

- Waiting 占位页和已绑定队伍页面左上角显示 `Project Natsume`，下一行依次为 `by`、作者头像和 `4o3F`。
- 作者头像使用 48px 圆形展示，署名与项目名分行；学校展示区域为页头预留空间，保留队伍、座位与右上角离线标识。
- Client 打包时通过公开 Gravatar 资料拉取 512×512 PNG，无需邮箱哈希或 API Token；头像直接随 Deb 安装到 `/usr/share/natsume/author-avatar.png`。
- CI 和本地打包共用下载步骤，校验头像格式、尺寸及包内文件与权限；下载或校验失败会停止打包，避免交付缺图或沿用旧图。
- Agent 只在窗口创建时从本地读取头像，不在编译、安装脚本或运行时下载；缺失或不可读的头像不会阻塞 Waiting 与首帧就绪。

## 升级

本次没有数据库 migration、Device Control 协议或本地 IPC 变更，无需重新注册设备或重建 Binding。
新增展示由 `natsume-client` 提供；在维护窗口升级 Client 并重新启动 Waiting 会话后生效。

源码打包新增 `AUTHOR_AVATAR_FILE` 输入。使用 `just package-client` 或 CI 打包入口会自动准备头像；直接调用 nFPM 时，按更新后的部署文档先运行 `packaging/client/prepare-avatar.py`。
