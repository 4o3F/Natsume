# v2.10.3

**Devices Web Panel 新增连接状态筛选、设备搜索和一键重置。**

## 主要变化

- Connection 支持 Online、Connected, awaiting fresh state 和 Offline 多选，默认全部选中；等待新状态的连接不算 Online。
- 连接筛选与生命周期筛选、搜索取交集；搜索忽略首尾空白和大小写，匹配当前 Binding Target 座位号、完整 Device ID 或硬件 ID。
- 展示匹配设备数与当前生命周期范围总数，提供 Reset filters；空结果时筛选仍可用，轮询后重新应用当前筛选。
- Emergency IP 导出仍独立读取完整 Enabled/Disabled 名单，包含离线设备、排除 Revoked，不受搜索或列表筛选影响。

## 临时依赖安全例外

经仓库所有者明确批准，为现有 `zip 8.6.0` 添加以下三个独立的 cargo-deny 公告例外：

- [RUSTSEC-2026-0367](https://rustsec.org/advisories/RUSTSEC-2026-0367.html)：文件系统解压保留特权权限位。
- [RUSTSEC-2026-0368](https://rustsec.org/advisories/RUSTSEC-2026-0368.html)：文件系统解压创建指向目标目录之外的符号链接。
- [RUSTSEC-2026-0369](https://rustsec.org/advisories/RUSTSEC-2026-0369.html)：解压时通过符号链接修改目录之外目标的权限。

本次不升级 ZIP／Calamine、不引入 Git fork 或 vendored 源码。Calamine 正式版 0.36.1 仍要求 ZIP 8；Natsume 的工作簿校验与 Calamine 读取 ZIP entry 流，比赛导出在内存中写 ZIP，不调用上述文件系统解压 API。依据见 `crates/roster/src/workbook.rs` 和 `server/src/component/contest/export.rs`。

**这些例外是接受现有依赖的残余风险，不是漏洞修复。** `deny.toml` 记录批准日期、责任方及移除条件；每次 ZIP／Calamine 更新或归档 API 用法变化均需复审。Calamine 正式支持修复后的 ZIP 版本时移除这些临时例外；其他安全公告继续按原策略检查。

## 升级说明

工作区及 7 个本地 crate 同步到 2.10.3，CI／打包默认版本同步到 2.10.3~ci1。OpenAPI 仅版本元数据变化，生成的 TypeScript 接口不变；无数据库 migration、Device Control 或部署配置格式变化。升级 Server 后刷新浏览器以加载新版面板。
