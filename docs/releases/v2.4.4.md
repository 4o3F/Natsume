# v2.4.4

**限制数据库阻塞工作并发、复用 Logo 校验结果，并改进上传、导航与座位刷新体验。**

## 主要变化

- 数据库读写在提交阻塞工作前异步排队，共用与连接池容量一致的 10 个许可，避免并发请求为等待连接占用大量阻塞线程。
- 数据库排队、阻塞调度和连接获取共用 30 秒预算；取消调用方不会提前释放已提交工作的许可，原有事务和 SQL busy timeout 行为不变。
- 学校 Logo 列表增加最多 1024 个路径的校验结果缓存。每次仍重新扫描目录、匹配文件名和检查文件指纹，支持文件替换、权限变化与损坏修复后的重新校验；同路径并发请求共享校验结果。
- Logo 图片下载、ETag 和名单 ZIP 导出仍读取并校验当前文件，不使用列表缓存代替实际数据。
- Seats 页面自动刷新，并在表格右上角显示刷新时间。
- Preparation 的 XLSX 选择器改为支持拖拽与点击选择的上传卡片；导航栏标识当前页面。
- 修正 tracing 测试中首次调用点注册受其他线程影响的问题，补充独立进程回归测试，不改变生产日志行为。

## 升级

本次没有数据库 migration 或 Device Control 协议变更。Web 更新随 Server 提供，无需重新注册设备或重建 Binding。

性能修复已通过本地回归测试；真实 Server 的吞吐、延迟和资源改善仍待后续复测确认。
