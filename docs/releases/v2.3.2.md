**升级 Rustls 修复 TLS 安全公告，并将依赖审计纳入 pre-commit；包含 Gateway 域名和 Firefox 入口修复。**

## 主要变化

- Rustls 最低版本和锁定版本升至 0.23.45，修复 [RUSTSEC-2026-0285](https://github.com/rustls/rustls/security/advisories/GHSA-2mjx-qc3c-rqvc)：TLS 1.3 握手消息在错误加密阶段被接受。同步升级其要求的 rustls-webpki 和 AWS-LC 依赖。
- `just pre-commit` 首先执行 `cargo deny check`，依赖安全公告、重复版本、许可证或来源检查失败即停止后续提交检查。
- Client 启动时由 Device Daemon 解析 `[site].gateway_hostname` 并通过固定 D-Bus 能力传给 Helper；Helper 只校验域名并维护本机 hosts、Firefox 主页和比赛书签，不读取 Client 配置。
- Gateway 配置同步保留其他地址、书签与 CA，重复启动保持幂等；无需在镜像中烘焙赛事域名，也不依赖 Server 在线或重新 Enrollment。

## 升级

已完成 Wayland 集成的 v2.3.0／v2.3.1 系统可在维护期原地安装完整 Server、Client Deb，然后显式重启对应服务：

```sh
# Server 上
sudo systemctl restart natsume-server.service
# Client 上
sudo systemctl restart natsume-privileged-helper.service natsume-device-daemon.service
```

完全退出再打开 Firefox，检查 Gateway 解析和浏览器入口。保留数据库、设备身份、凭据、Binding、Home 状态、完整配置与 CA；不重新 bootstrap。本次没有新增 migration 或控制/Agent 协议变化。

更早的 X11 Client 仍须完成原生 Wayland 镜像配置迁移。具体步骤见[部署与升级手册](https://github.com/4o3F/Natsume/blob/v2.3.2/docs/operations-deployment.zh-CN.md#upgrade-v2-3-2)。
