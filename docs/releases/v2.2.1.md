**补丁发布：设备列表支持 Server 端生命周期筛选，日常运维视图默认隐藏已撤销设备。**

## 主要变化

- `GET /api/v2/devices` 新增可选 `state` 查询参数：`enabled`、`disabled`、`revoked`、`non_revoked`、`all`。不提供参数仍返回全部记录；非法参数返回 HTTP 400。
- Devices 和 Targets 增加 **Device state** 筛选器，默认显示 Enabled + Disabled。Revoke 后设备从默认列表消失，仍可在 Revoked／All 视图查询，撤销记录和控制密钥语义不变。
- 筛选值纳入请求缓存键，迟到的旧筛选响应不会覆盖当前视图；空结果时仍可切换筛选。
- Targets 的全部 Enabled 操作始终使用 Server 的全局范围，即使当前列表只显示 Disabled／Revoked 或为空，也不会缩小批量操作范围。

## 从 v2.2.0 升级

备份数据库、密钥和配置后安装 `natsume-server_2.2.1_amd64.deb`，显式重启 Server，并完全刷新管理员 Web。
本补丁没有新增数据库 migration，控制／本地 IPC 协议不变；原有兼容 Client 可继续使用。

从 v2.1.0 或更早版本升级时，仍须执行此前的 HTTP API 或控制协议迁移步骤。详细说明见[最新部署与升级手册](https://github.com/4o3F/Natsume/blob/v2.2.1/docs/operations-deployment.zh-CN.md#upgrade-v2-2-1)。
