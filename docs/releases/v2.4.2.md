# v2.4.2

**统一 Web 状态筛选与页面布局，修复集体关机的前端提交流程。**

## 主要变化

- Devices、Targets 和 Seats 使用统一的多选 checkbox 样式，支持键盘操作；Targets 筛选器与搜索栏对齐。
- Seats 补齐页面标题、优化列宽和状态图标，保留绑定状态行底色；筛选结果为空时仍可修改条件。
- 批量 Session/Home 操作与 Power Control 分区展示，适配较窄屏幕；关机确认弹窗清楚展示在线范围、60 秒有效期及确认文字。
- 修复前端请求校验遗漏 `power_off` 和 `all_online_enabled` 导致关机请求无法发送的问题；支持原请求保存、恢复及同 ID 重试，拒绝不合法的动作与范围组合。
- 关机提交结果正确标识在线 Enabled 范围，不提供不受支持的逐设备重试；取消确认后清空输入。

## 升级

本次没有新增数据库 migration 或 Device Control 协议变更。可原地升级完整 Server 与 Client Deb，保留现有数据库、设备身份、Binding 与 Home 状态；无需重新 bootstrap。
