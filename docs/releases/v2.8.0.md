# v2.8.0

**Web 面板将账户操作与权限等级集中到用户名下拉菜单。**

## 主要变化

- 右上角以真实用户名作为菜单入口，不再显示截短的 Operator UUID。权限等级、Change password 和 Logout 统一放在下拉菜单内，admin/viewer 均可使用。
- 菜单支持键盘导航、Esc 关闭及点击菜单外关闭；长用户名在入口处截断，在菜单中完整展示。桌面及移动端保持菜单不超出视口。
- 登录与查询会话的 `SessionResponse` 新增必填字符串 `username`，取自 Server 中当前账户的用户名。OpenAPI 与生成的 TypeScript 类型同步更新；角色及授权规则不变。
- 保留改密后的会话撤销、退出流程和失败提示；退出请求进行期间不能重复提交。

## 升级说明

本次变更不增加数据库 migration，不修改 Device Control、本地 IPC 或部署配置格式。Server 包包含配套 Web 静态资源，升级并重启 Server 后刷新浏览器即可使用新版菜单。直接消费会话 API 的工具应接受新增的 `username` 字段；拒绝未知字段的客户端需同步更新响应模型。

## 验证范围

本地定向验证通过：37 项 Playwright 浏览器测试（覆盖菜单、会话边界、用户与密码流程）、25 项前端单元测试、2 项会话 HTTP 测试及16 项 OpenAPI 契约测试。`SKIP=rust-test,web-test prek run --all-files` 的依赖策略、格式、Lint 和 Clippy 检查通过；全量测试留给发布 CI。浏览器验证使用 mock API 数据，未执行本次版本的实际部署升级或完整生产 HTTPS 验收。
