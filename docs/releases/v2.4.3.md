# v2.4.3

**优化 Targets 提交结果、设备详情及 Enrollment window 状态展示。**

## 主要变化

- Targets 提交结果使用统计卡片与可折叠明细表，支持仅查看被拒绝的设备及其原因；Submitted／Rejected 使用无背景、无边框的图标与文字。
- 明确区分 Server 已接受提交与设备实际完成，保留结果未确认时的原请求重试，以及仅重试明确被拒绝设备的行为。
- 单设备详情按 Target／Actual、桌面就绪状态和 epoch 分组展示，突出异常说明。
- Enrollment window 使用大号状态、图标和不同色调区分 Open、Closed、Loading 与 Unavailable，并明确自动审批和人工审批的区别；读取失败时不继续展示上次的 Open 状态。
- Accounts 和 Seats 的缺失 Logo 提示改为统一图标，保留无障碍名称。
- 补充状态切换、结果筛选、无边框状态展示和桌面／窄屏布局的浏览器回归测试。

## 升级

本次没有数据库 migration 或 Device Control 协议变更。Web 更新随 Server 提供，无需重新注册设备或重建 Binding。
