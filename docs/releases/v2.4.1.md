# v2.4.1

**修复 pre-commit 入口和 Power Control migration 的 schema contract。**

## 主要变化

- 所有提交前检查由 `prek` 的 `.pre-commit-config.yaml` 统一运行，覆盖依赖策略、Web Prettier/lint/test、Rust Clippy/test；不再维护 `just pre-commit` 入口。
- schema contract 已纳入 Power Control 的第四个 migration、严格表数量与级联删除关系。
- 修正 Web 目标操作页面的 Prettier 格式。

## 升级

可原地安装完整 Server 与 Client Deb，并重启对应服务。保留数据库、设备身份、Control/Gateway 凭据、Binding 与 Home 状态；不需要重新 bootstrap 或清除数据。
